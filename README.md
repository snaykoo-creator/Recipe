# рецепт.ру — кулинарный портал

## Функциональность

- Каталог рецептов с фильтрацией по категориям (супы, второе, десерты) и текстовым поиском.
- Регистрация и авторизация пользователей.
- Личный кабинет: изменение ФИО, загрузка аватара, просмотр истории действий (демо-режим).
- Административная панель (доступ по паролю, указанному в файле ADMIN_ACCESS.txt):
  - просмотр списка зарегистрированных пользователей;
  - экспорт списка пользователей в JSON;
  - удаление всех пользователей;
  - управление глобальным объявлением, отображаемым на всех страницах сайта.
- Адаптивная вёрстка: бургер-меню на мобильных устройствах.
- Слайдер на главной странице.

## Технологии

- HTML5
- CSS3 (методология БЭМ, flexbox, гриды)
- JavaScript (ES6, работа с DOM, localStorage)
- Google Fonts (IBM Plex Sans)

## Структура проекта

- `index.html` — главная страница со слайдером, описанием проекта и отзывами.
- `recipes.html` — каталог рецептов с фильтрацией и модальными окнами.
- `registration.html` — форма регистрации нового пользователя.
- `account.html` — личный кабинет (вход, просмотр и редактирование профиля).
- `admin.html` — панель администратора.
- `404.html` — страница ошибки 404.
- `css/styles.css` — единый файл стилей.
- `js/main.js` — вся клиентская логика (слайдер, фильтрация, регистрация, localStorage, админка).
- `images/` — директория с изображениями.
- `ADMIN_ACCESS.txt` — файл, содержащий пароль для входа в административную панель.
  
## Доступ к административной панели

Для входа в панель администратора необходимо:

1. На любой странице сайта прокрутить страницу вниз до подвала (footer).
2. В блоке контактов найти ссылку **«Админ»** (расположена после города Благовещенск).
3. Перейти по ссылке на страницу `admin.html`.
4. Ввести пароль администратора (по умолчанию: `admin123`).

После успешной авторизации становятся доступны следующие функции:
- просмотр списка зарегистрированных пользователей;
- удаление отдельных пользователей;
- экспорт списка пользователей в JSON-файл;
- полная очистка базы пользователей;
- управление глобальным объявлением, отображаемым на всех страницах сайта.

Сессия администратора сохраняется до закрытия вкладки браузера.

## Особенности реализации

- Все данные (пользователи, настройки сайта) хранятся в `localStorage`. Ключи:
- `recipe_users` — массив зарегистрированных пользователей.
- `recipe_current_user` — текущий авторизованный пользователь.
- `recipe_site_settings` — настройки глобального объявления.
- Массив рецептов жёстко задан в `main.js`.
- Аватар по умолчанию — `images/prof.jpg`. Пользователь может загрузить своё фото (сохраняется как DataURL).
